# Agente-001

## Sobre o jogo

O jogador assume o papel de um agente secreto encarregado de impedir uma operação ilegal. Durante sua missão, deverá enfrentar inimigos, superar obstáculos e utilizar armas especiais capazes de modificar elementos do cenário e dos adversários por meio de conceitos de programação.

O jogo busca transformar conceitos como condicionais, variáveis e estruturas de repetição em desafios interativos.

## Funcionalidades e objetivos

- [x] Movimentação básica do personagem.
- [x] Sistema de plataformas e colisões.
- [x] Inimigos com movimentação e colisões.
- [x] Sistema de múltiplos personagens.
- [ ] Menu inicial.
- [ ] Múltiplas fases.
- [ ] Animações utilizando spritesheets.
- [ ] Música e efeitos sonoros.
- [x] Interação com teclado e mouse.
- [ ] Instalador para Windows.

## Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/I-ALucas-I/Agente-001.git
   ```

2. Abra o projeto no Visual Studio.

3. Certifique-se de que a biblioteca **Allegro 5** esteja instalada e configurada corretamente.

4. Compile e execute o projeto.
